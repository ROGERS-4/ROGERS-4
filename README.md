### Plugin Categories

**AI Modules**
hd, sora, flux, vision, wormgpt, muslimai, bibleai, speechwriter, transcribe, shazam, bing, imageedit, removebg, vocalremover

**Tools**
sharephone, onwhatsapp, fancy, tts, translate, langcodes, scan, walink, qrgenerator

**Search and Intelligence**
google, brave, news, movie, lyrics, yts, image, wagroup, ghfollowers, ghfollowing

**GPT System**
gpt, gpthistory, lastchat, clearai

**Uploader and Converters**
Media converters (mp3, mp4, gif, ptt), view once tools, audio and document processing

**Education**
math, dictionary, poem, fruit

**Fun and Random**
jokes, memes, facts, truth, dare, paranoia, quote, inspirobot

**Group Management**
kick, add, promote, demote, tagall, hidetag, open and close time, polls and approvals

**Owner and Admin Power**
eval, shell, fetch, sudo management, profile and privacy tools, system control commands

**Media Generation**
neon, glitch, galaxy, graffiti, fire, thunder, cartoon, tattoo, zodiac, intro videos and effects

**Downloaders**
YouTube, TikTok, Instagram, Facebook, Twitter, Spotify, SoundCloud, APK and media fetchers

**Stalker and OSINT Tools**
GitHub, NPM, YouTube, Instagram, TikTok, country and channel intelligence

**System and Settings**
auto reply, auto read, anti delete, anti link, chatbot, status automation, prefix, timezone, presence

**Stickers**
sticker maker, tgs support, sticker search
